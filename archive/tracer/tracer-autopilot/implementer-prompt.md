# Implementation prompt

Use the shared [implementation prompt](../tracer-implement/implementer-prompt.md) inline or for a justified delegation. Give one context the cohesive change, not a fresh agent for each task. Resolve its placeholders from the delivery's original requirements, short plan, agreed safety limits, and focused verification scope.

For delegated work, use `.tracer/implement/task-N-brief.md` and `task-N-report.md`; inline work can use the ledger. Reuse the same implementation context for related tasks and corrections. Routine implementation choices need no user checkpoint, but custom infrastructure or stronger guarantees still require the architecture decision described in Autopilot.
